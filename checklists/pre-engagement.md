# Pre-engagement checklist

Generic checklist. No client details.

- [ ] Written authorization is signed and on file
- [ ] Scope is listed by asset (IPs, domains, applications), with explicit exclusions
- [ ] Testing window is agreed, including time zone
- [ ] Rules of engagement cover denial-of-service, social engineering, and data handling
- [ ] Emergency contact and escalation path are confirmed
- [ ] Credentials provided for testing are stored securely and deleted at the end
- [ ] Evidence handling and retention period are agreed
- [ ] Report delivery date and recipients are agreed
