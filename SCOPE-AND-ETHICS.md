# Scope and ethics

Everything in this portfolio comes from one of these sources:

- a self-built lab that I own,
- a deliberately vulnerable application (such as OWASP Juice Shop or DVWA),
- a CTF or training platform, following its writeup rules,
- an engagement with written authorization, with identifying details removed,
- a vulnerability disclosed through a bug bounty or coordinated disclosure program.

I don't publish findings from systems I wasn't authorized to test. Exploit details for live or unpatched systems are withheld until they're fixed. Examples use RFC 5737 addresses and placeholder names.

Tools in this portfolio are for authorized use only. Any tool that touches a network checks its target against a scope file before it runs.
